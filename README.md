## 🛠️ Wymagania

* **JDK** (zalecana wersja 17 lub nowsza)
* **Gradle** (jeśli nie korzystasz z wrappera gradlew)
* **Aktywne połączenie z internetem**

## ⚙️ Instalacja i Konfiguracja

Aby uruchomić aplikację lokalnie, wykonaj poniższe kroki:

### 1. Pobierz klucz API Gemini
* Zaloguj się do **Google AI Studio**.
* Wygeneruj nowy klucz API (**API Key**).

## 🚀 Uruchamianie

Projekt jest zarządzany przez system Gradle. Aby zbudować i uruchomić aplikację, otwórz terminal w folderze projektu i wpisz:

### System Windows:
```bash
./gradlew build
./gradlew run
```

### System Linux / macOS:
```bash
chmod +x gradlew
./gradlew build
./gradlew run
```
